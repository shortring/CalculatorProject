계산기 프로젝트

해당 프로젝트는 스파르타클럽의 내일배움캠프에서 진행하는 과제용 프로젝트입니다.

버전에 따라 브랜치를 나누었으며 내용은 아래와 같습니다

LV1
: 클래스 없이 자바의 기본 문법만을 사용하여 구현한 계산기 (필수 구현 기능) 
LV2
: 객체 지향 개념을 적용하여 클래스 정의, 연산을 수행하는 메소드 작성한 계산기(필수 구현 기능)
LV2-version1.1
: 객체 지향 개념을 적용하여 클래스 정의, 연산을 수행하는 메소드 작성한 계산기(LV2에서 try catch문을 통한 예외 처리문 추가)
LV3
: 자바의 Enum, 제네릭, 람다 & 스트림을 적용한 계산기 (도전 구현 기능)


세부 구현 기능은 아래와 같습니다

1. 두 수를 입력받기 (lv1~2는 정수, lv3은 실수)
2. 문자열로 exit를 입력받는다면 계산기 프로그램을 종료하고 그렇지 않다면 계속 계산기 프로그램을 반복 실행합니다.
3. 더하기, 빼기, 나누기, 곱하기, 거듭제곱, 나머지 연산을 수행할 수 있습니다(거듭제곱, 나머지 연산은 lv3기능)
4. 계산을 완료하면 결과값을 출력합니다
5. 결과값들은 모두 리스트로 저장해둡니다
6. view를 입력하면 지금까지 계산한 값들을 리스트로 출력합니다
7. delete를 입력하면 저장된 값들 중 가장 먼저 저장되었던 값 1개를 삭제합니다
8. 계산을 완료할때마다 저장되어있는 결과값들 중 해당 값보다 큰 값들을 리스트로 출력합니다(lv3기능)
